# Semana 03 — EDA e Preparação dos Dados

## Visão geral do notebook
A terceira semana é sobre entender a base antes de modelar. O notebook mostra que a maioria dos problemas de modelagem nasce antes do treino: dados faltantes, colunas inconsistentes, valores extremos e ruídos podem comprometer tudo.

### Em poucas palavras
A aula trata de:
- análise exploratória de dados;
- estatísticas do conjunto;
- identificação de outliers;
- correlação entre variáveis;
- limpeza e preparação antes do treinamento.

## O que aparece no notebook
1. Verificação dos tipos e estrutura dos dados.
2. Análise de valores ausentes e inconsistentes.
3. Boxplot e medidas descritivas para detectar anomalias.
4. Correlação entre variáveis e relação entre atributos.
5. Limpeza da base para reduzir erro antes do modelo.

## Conceitos mais importantes
- EDA: exploração inicial dos dados para entender sua qualidade e comportamento.
- Outlier: valor muito distante do restante do conjunto.
- Correlacão: relação entre duas variáveis.
- Preparação dos dados: transformar a base em algo consistente, confiável e útil para modelagem.

## Como ler esse notebook de forma simples
O notebook funciona como uma inspeção da base antes do treinamento. Se a base está bagunçada, o modelo aprende ruído e não padrão. A qualidade da análise depende muito da qualidade da preparação.

## Conclusão didática
Essa semana ensina que a limpeza de dados não é uma etapa burocrática; é parte central da solução. Em Ciência de Dados, o melhor modelo muitas vezes começa com uma boa revisão da base.

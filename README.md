# 📊 Repositório de Ciência de Dados

Este repositório reúne as aulas de Ciência de Dados organizadas por semana, com materiais em notebook, resumos em Markdown e exemplos práticos em Python.

## 🎯 Objetivo

Organizar o conteúdo da disciplina em uma estrutura clara e didática, permitindo que o aluno navegue facilmente por:

- conceitos teóricos;
- notebooks com a aula original;
- exemplos de código executáveis;
- materiais visuais e datasets complementares.

## 🗂️ Estrutura do repositório

A organização foi montada em semanas, cada uma contendo:

- resumo da aula em Markdown;
- notebook `.ipynb` original ou estruturado para a semana;
- arquivo `exemplo_codigo.py`;
- pasta `images/` para gráficos e materiais visuais;
- pasta `materiais/` com os datasets utilizados.

## 🧠 Temas principais

O material aborda tópicos essenciais da disciplina, como:

- estatística descritiva;
- amostragem e escalas de medição;
- CRISP-DM e ciclo de vida de projetos de dados;
- análise exploratória de dados (EDA);
- métricas de classificação;
- testes de hipótese;
- séries temporais;
- modelos preditivos e redes neurais.

## ✅ Como usar

1. Acesse a pasta da semana desejada.
2. Leia o resumo em Markdown.
3. Abra o notebook `.ipynb` para acompanhar a explicação visual.
4. Execute o arquivo `exemplo_codigo.py` para praticar os conceitos.
5. Se necessário, use a pasta `materiais` para reproduzir os datasets.
